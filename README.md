# 护眼提醒（Eye Rest）

一款运行在 Windows 上的轻量护眼计时工具，按 20-20-20 原则提醒你定时休息：默认工作 20 分钟，然后远眺约 6 米外 20 秒。应用会在系统托盘持续运行，隐藏主窗口后仍会继续计时。

## 功能

- 自定义工作时长（1–240 分钟）和休息时长（1–300 秒），默认值为 20 分钟和 20 秒。
- 休息开始时显示置顶提醒窗口，可稍后 5 分钟再次提醒，或提前结束本次休息。
- 暂停、继续计时；也可以从系统托盘打开窗口、暂停计时或退出应用。
- 查看今日工作时长、休息时长和完整休息次数。暂停期间不累计时长，跳过或未完成的休息不计入次数。
- 可设置登录 Windows 后启动，以及锁屏时暂停、解锁后继续。
- 睡眠期间不计入工作或休息时长；唤醒后重新校准倒计时。
- 设置和今日统计保存在本机。重启应用后设置和当日统计会保留，倒计时从新的工作周期开始。

## 环境要求

- Windows 10 或 Windows 11
- Node.js 22.12 或更高版本
- pnpm

## 开发运行

在项目根目录执行：

```powershell
pnpm install
pnpm dev
```

## 构建与预览

```powershell
# 构建应用
pnpm build

# 启动构建后的应用进行预览
pnpm preview
```

## 打包 Windows 便携版

在 Windows 上执行：

```powershell
pnpm pack:win
```

打包文件生成在 `release/` 目录中，通常为 `Eye Rest 0.1.0.exe`。该文件名会随应用版本调整。

## 使用说明

- 默认启动后立即开始工作倒计时。关闭主窗口会将窗口隐藏到系统托盘，不会退出应用。
- 点击主窗口右上角的设置按钮可调整工作、休息时长和启动选项。保存时会按当前阶段重新开始对应倒计时。
- 工作计时暂停后，可调整本次工作时长；开始计时后该时长也会保存为新的默认设置。
- 到达休息时间后，提醒窗口会显示“看向 6 米外，让眼睛放松”。点击“5 分钟后提醒”会结束当前提醒并安排 5 分钟后的下一次提醒。
- 今日统计按本机日期计算，仅显示当天数据；完整休息次数只在休息倒计时自然结束时增加。

### 快速预览提醒

打开主窗口右上角的设置，将工作时长设为 1 分钟、休息时长设为 1 秒并保存，然后等待提醒出现。

## 本机数据

应用使用 Electron 的用户数据目录保存 `timer-settings.json` 和 `daily-stats.json`。数据仅保存在本机；具体目录由 Electron 和当前 Windows 用户配置决定。

## 项目结构

```text
src/
  main/       Electron 主进程和计时逻辑
  preload/    主进程与界面之间的安全桥接
  renderer/   Vue 用户界面
  assets/     图标和字体
scripts/      开发与预览启动脚本
```
